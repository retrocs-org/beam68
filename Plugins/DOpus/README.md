# DOpus 0.1

Open drawers and reveal selected results in Directory Opus.

Use dopus:<drawer>. Supports Directory Opus 5 and ScanDir fallback for Opus 4.

Settings are owned by this plugin. Existing main configuration values are used
until a plugin settings file overrides them. Disable the plugin to disable its
integration with normal search result actions. Protocol 1; Beam68 0.2; MIT.
