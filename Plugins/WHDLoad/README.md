# WHDLoad 0.1

Find and launch installed WHDLoad games.

Enter searches games; choose a result, then Enter to play. Set the WHDLoad executable in Settings.

Settings are owned by this plugin. Existing main configuration values are used
until a plugin settings file overrides them. Disable the plugin to disable its
integration with normal search result actions. Protocol 1; Beam68 0.2; MIT.

Enabling WHDLoad starts background discovery when the launcher loads its plugins.
It uses General Indexing directories, exclusions and depth, including Unlimited.
Reindex restarts discovery. Incomplete scans retain previously indexed games.
Disabling the plugin removes its games during the next index refresh.
